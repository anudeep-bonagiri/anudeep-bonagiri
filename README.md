## 👋 About

I build agentic AI systems, then measure whether they actually work. Most of what's pinned below ships with an evaluation harness, an architecture write-up, or both. I would rather show a retrieval score that dropped than a demo that always wins.

## 🔭 Featured Work

| Project | What it is |
| :--- | :--- |
| **[Interview Insight Search](https://github.com/anudeep-bonagiri/interview-insight-search)** `MIT` | Semantic search and grounded synthesis over interview transcripts. Hybrid BM25 + embedding retrieval with Reciprocal Rank Fusion, timestamp-level citations, and a labeled eval set (recall@k, MRR, nDCG) that **fails CI when retrieval quality regresses**. [Live demo](https://interview-insight-search.streamlit.app) |
| **[Provenance Guard](https://github.com/anudeep-bonagiri/provenance-guard)** `MIT` | AI-content provenance backend combining an LLM classifier, stylometry, and lexical signals. Conflict-aware confidence calibration and asymmetric thresholds avoid falsely accusing human writers, and every decision lands in a structured audit log with an appeal path. |
| **[Sync AI](https://github.com/anudeep-bonagiri/self-healing-network)** `MIT` | Self-healing network intelligence that detects anomalies, predicts failures, and autonomously remediates them through multi-agent reasoning over live telemetry. Built at HackUTD 2025. |
| **[AetherVision](https://github.com/anudeep-bonagiri/aethervision)** `MIT` | Local multimodal vision workbench running Florence-2, Depth Anything V2, and CLIP on Apple Silicon GPU (MPS) behind one FastAPI inference server, with an interactive dashboard. |
| **[NeuroSync](https://github.com/anudeep-bonagiri/neuroSync)** `MIT` | Neuroscience research platform pairing LLM-generated persona insights with interactive 3D neural connectivity visualization (FastAPI + Next.js + Llama 3). |
| **[GrowFi](https://github.com/anudeep-bonagiri/growfi)** `MIT` | Gamified financial-literacy platform with goal tracking, progression mechanics, and microcredit scoring. React/TypeScript + Node/Express, built at HackRice 15. |

**Also built:** [TakeMeter](https://github.com/anudeep-bonagiri/takemeter) (fine-tuned DistilBERT classifier with baselines and ablations) · [DJ Agent](https://github.com/anudeep-bonagiri/dj-agent) (agentic RAG with tool calling) · [Lyra](https://github.com/anudeep-bonagiri/lyra-f1-dashboard) (live F1 telemetry + LLM commentary) · [pathCopier](https://github.com/anudeep-bonagiri/pathCopier) (macOS Finder Quick Action)

## 🌱 Open Source

I publish my work under open licenses and keep it documented, tested, and reproducible.

- **[pathCopier](https://github.com/anudeep-bonagiri/pathCopier)** `MIT` · macOS Finder Quick Action that copies any file's git-root-relative path. Shipped as a signed Service, released v1.0.0.
- **[Interview Insight Search](https://github.com/anudeep-bonagiri/interview-insight-search)** `MIT` · retrieval pipeline with a labeled eval harness that gates CI, so a drop in recall@k breaks the build.
- **[AetherVision](https://github.com/anudeep-bonagiri/aethervision)** `MIT` · one FastAPI server that unifies three local vision models behind a single API.

**Contributions to other projects:** [eGEOagents PR #7](https://github.com/mverab/eGEOagents/pull/7) (merged) added markdown frontmatter isolation and an HTML export pipeline to a generative-engine-optimization toolkit.
